\# Framer Motion Generator Skill



\## Goal

To ensure all page animations meet Awwwards-level cinematic standards using Framer Motion.



\## Instructions

When the user asks to animate components, headers, grids, or page transitions, apply the following design systems:

1\. \*\*Cubic Bezier Curves:\*\* Use fluid custom cubic-bezier transitions `\[0.16, 1, 0.3, 1]` rather than generic CSS springs for an elegant, premium weight.

2\. \*\*Staggered Delays:\*\* Apply staggered entrance delays (`staggerChildren`) to multi-card elements, like the Selected Projects grid or Core Competencies list.

3\. \*\*Text Reveals:\*\* Utilize character or word-level opacity split animations for the main text header strings (e.g., "ALDRIN K JOHNI").



\## Constraints

\- Do not use overly aggressive or fast bounce springs. Keep animations subtle and atmospheric.

\- Ensure all animated properties utilize `will-change` where necessary to avoid performance degradation or layout lag on mobile browsers.
